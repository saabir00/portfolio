# sabirmehdikhanli.me

Personal portfolio of Sabir Mehdikhanli — SOC Analyst / Blue Team.

- Static site: a single `index.html` (no build step)
- Hosted on Netlify, custom domain `sabirmehdikhanli.me`
- "Hire me" form uses **Netlify Forms** (form name: `contact`, honeypot spam protection)
- Security headers in `_headers` (CSP, HSTS, X-Frame-Options, etc.)
